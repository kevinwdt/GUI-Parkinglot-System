# GUI-Parkinglot-System

The YorkU Parking System is a user friendly platform designed to manage the university campus's parking lot system. It allows students, faculty, staff, and visitors to easily book parking spots while giving administrators the tools they need to oversee the process. The system allows users to do everything from registration and payments to real-time parking space updates, ensuring a smooth experience for both users and admins. For example, users can reserve spots, extend bookings, or cancel with automatic deposit refunds, while admins can approve new users, adjust parking availability, and monitor occupancy, all through an intuitive interface.

The project was built with a focus on clean, modular code to make future updates and maintenance easier. It uses common design patterns like Factory for creating different user types, Observer for live parking space updates, and Strategy for flexible payment options (credit card, mobile pay, etc.). The backend relies on CSV files to store data, keeping things simple, while the frontend is built with Java Swing for a straightforward, user friendly interface. By separating the system into clear components, like user management, booking, payments, and admin controls, the code stays organized and adaptable. This approach not only makes the system reliable today but also ensures it can grow as needs change in the future.
